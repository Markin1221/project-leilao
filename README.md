# project-leilao

Análise e gestão de compra/venda de motos de leilão (Copart – Vitória de Santo Antão).

## Rodar
Precisa do Python 3.10+ instalado. Dê dois cliques em `iniciar.bat`.
- PC: http://localhost:5000
- Celular (mesma Wi-Fi): http://IP-DO-PC:5000 (na primeira vez, permita o Python no firewall do Windows)

## Etapas
1. ✅ Calculadora "vale a pena?" (com FIPE) + gestão de motos, gastos e lucro
2. Análise colando o link do lote da Copart
3. Robô (Playwright) que grava os valores de venda do leilão de quinta + sugestões e alertas no Telegram

Os dados ficam em `leilao.db` (fora do git).
